# Register nexacode.is-a.dev

NexaCode Studio is a developer-focused AI coding-agent project. It explores a hybrid architecture where planning and orchestration are handled by a backend while approved code, filesystem, test, Git, and IDE operations execute locally through an IntelliJ client.

Live project website:
https://ngocthanhluong.github.io/nexa-code-intellij-extension/

Repository:
https://github.com/NgocThanhLuong/nexa-code-intellij-extension

Before submitting the registration PR, attach a screenshot of the live website and copy `is-a-dev/nexacode.json` to `domains/nexacode.json` in a fork of `is-a-dev/register`.
