03 · Workflow

From development task to verified patch.

The workflow emphasizes inspectable steps and standard software-engineering feedback loops.

01INSPECT

Understand the project

Search code, read relevant files and identify the affected symbols.

02EDIT

Apply focused changes

Use bounded file and patch operations rather than opaque workspace mutation.

03VERIFY

Run project checks

Execute tests, inspect errors and read logs where required.

04REVIEW

Inspect the final diff

Review Git changes and confirm the implementation matches the task.

Project principles

Developer automation is most useful when workspace access is explicit, changes are reviewable and verification is part of the workflow.
