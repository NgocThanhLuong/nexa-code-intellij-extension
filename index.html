03 · Workflow

From intent to reviewable change.

A coding task becomes a sequence of observable decisions and local actions rather than a single black-box generation step.

01DESCRIBE

Give NexaCode a goal

Start with a bug, refactor, feature or project objective.

02PLAN

Build an execution path

The orchestrator reasons about the task and selects required tools.

03EXECUTE

Perform controlled local work

Approved operations run against the real developer workspace.

04VERIFY

Review the outcome

Inspect patches, test results and continue or accept the run.

Project principles

Powerful coding agents are most useful when execution is observable, permissions are explicit and developers stay in control.
